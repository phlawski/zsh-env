# Linux zsh env for my Pi

## Antidote

Follow instructions from: https://antidote.sh/install

## Copy files

Copy `.zshrc` and `.zsh_plugins.txt` to your `$HOME` directory.

## Diff-so-fancy

See: https://github.com/aos/dsf-debian, https://github.com/so-fancy/diff-so-fancy

## btop

```zsh
sudo apt install btop
```

## Kubernetes

This setup enables some K8S goodies if the `kubectl` is installed (requires **snap** install).
Additional stuff required is `kubecolor` (see: https://github.com/kubecolor/kubecolor)
